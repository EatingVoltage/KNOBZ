# KNOBZ printed parts

Replacement parts for the KNOBZ enclosure. If one breaks, print a new one.

| Part | File | Qty |
|---|---|---|
| Case | `knobz_case.stl` | 1 |
| Button cap | `buttoncap.stl` | 7 (one per button) |
| Bottom spacer | `knobz_bottom_spacer.stl` | 1 |

## Print settings

- Material: PETG
- Layer height: 0.2 mm
- Supports: none

The bottom spacer sits between the main PCB and the bottom plate. The bottom plate is
itself a PCB, not a printed part.
